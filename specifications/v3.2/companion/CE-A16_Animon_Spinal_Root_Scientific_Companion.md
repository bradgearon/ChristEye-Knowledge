# CE-A16 · Spinal Root and Axon Evidence — Scientific Companion v3.2

**Primary question Q16:** How would we establish that an actual source-qualified spinal-derived neural structure **contributes** to a bounded task relationship, rather than merely being present next to a responding system?

A proposed Animon is an individual developmental system, not a neuron, organoid or fixed memory location. Its proposed spinal **Root tissue** is physical. A tested **functional Root** is a retained relation; assigning a functional Root to particular spinal anatomy is an additional scientific hypothesis requiring new evidence. See [ANIMON/1](../../../ontology/ANIMON_V1.md), [CE-A16 engineering design](../design/CE-A16_Animon_Spinal_Root_Design.md) and [v3.1 source](../../v3/companion/CE-A16_root_registry_and_mapping_Companion.md).

**Study scope warning:** Gibbons et al. investigates human corticospinal axonal development and potential repair strategies. It provides a useful *methodological distinction* between anatomy, function and cell type, **not a proof of learning or long-term storage**.

| Ordinary feature / candidate | Biological context | What to measure or validate | What it cannot alone establish |
|---|---|---|---|

| SOX9, ALDH1L1, selected MCT/EAAT/Kir regulators | Astrocytic identity and metabolic/ionic support in specified systems | source-specific cell state, transport or electrophysiological health | transferable learned relation or consciousness |

No sequence, concentration, genetic construct, axon-growth method or stimulation schedule follows from this table. These are **candidate experimental observables**, whose appropriateness depends on a qualified preparation. A laboratory SOP must be independently selected and approved.

## 4. Four layers of proof and the mistaken inference each corrects

**Layer A: structural relation.** Tissue source identity, imaging geometry, actual axon tracks, contact/terminal characterization, temporal validity. False positive: incidental adjacency, region contamination, image segmentation error.

**Layer B: statistical dependence.** Repeated calibrated co-activity, time alignment, uncertainty, proper sampling and common-input assessment. False positive: one external electrode field or shared medium produces both traces.

**Layer C: possible directed functional influence.** A separately justified *site-approved* source-target study with controls for alternative electronic, neural and fluid paths. False positive: stimulation artifact or host decoder conveys the same information.

**Layer D: contribution to a task-specific retained relation.** A real previously specified task, training/exposure provenance, immutable decoder, delayed nonteacher test, old skill and health context, independent effect of the nominated candidate source. False positive: task labels leak through the electronic host or the child network succeeds only while a teacher is still connected.

**There is no automatic implication A→B→C→D.** Moreover C does not uniquely assign a stored engram to its source region; memory can be distributed and dynamically accessed. Each layer must keep its own scientific evidence status.

## 5. Spatial and temporal uncertainty model

For a proposed mapped axon observation, define a measurement M_i at location x_i and clock t_i, with an observational validity region V_i and uncertainty U_i. A simple geometry association can be recorded as a **candidate** only where both the spatial registration and the target assignment are justified.

A nominal latency is:

\[
\Delta t = t_{\mathrm{target}} - t_{\mathrm{source}}.
\]

If the clocks have uncertainties u_s and u_t with an independently justified covariance, timing uncertainty is not simply zero:

\[
u_{\Delta t}^{2} = u_s^{2} + u_t^{2} - 2\,\mathrm{Cov}(t_s,t_t).
\]

A positive latency with uncertainty **does not prove a direct axon**, because shared drives and multi-step circuitry may have delays too. The actual sampling rate, filtering, artifacts and clock synchronization must be characterized by the instrument owner; no Animon values exist yet.

For a 3D Soil region, *coverage* is meaningful only within its actual observable volume, optical instrument constraints, segmentation validity and uncertainty. A 2D culture count is not proof of tissue composition in a larger 3D preparation.

## 6. Study-design matrix for qualified investigators

| Primary question | Study comparison at the design level | Invalidating factor |
|---|---|---|
| Does source-specific axon structure exist? | qualified source/recipient morphology versus alternative regions and segmentation controls | missing source line, nonunique markers, field not registered |
| Is the apparent relation merely shared input? | source/target activity under independently reviewed control for shared electronic/environmental routes | unseen digital bridge, electrode crosstalk, common pulse |
| Does the proposed physical region alter a task? | separately reviewed region association with task test under a *frozen* evaluator | decoder changes or task answer leakage |
| Does task relation persist? | immediate versus specified delayed performance with teacher route off and old task controls | different codebook or ongoing feedback at delay |
| Is development being mistaken for more learning? | source- and maturation-matched comparisons, independent preparation replicates | new cells, physiological stress or maturation over time |
| Does observed molecular change explain a new Root? | independent actual molecular form/localization and a task-specific alternative analysis | generic excitability or better nutritional support explains response |

**No biological intervention regimen is selected here.** The relevant qualified institution owns experiment parameters, authorizations and legitimate controls. The statistical unit is generally the independent biological preparation/line/batch structure rather than each cell or electrode being counted as independent.

## 7. Digital evidence graph as a falsifiable scientific aid

The [root_evidence_edge.schema.json](../../../schemas/animon/root_evidence_edge.schema.json) and [axon_projection.schema.json](../../../schemas/biology/axon_projection.schema.json) enforce *typed statements* and explicit unknowns. A [design-stage fixture](../../../fixtures/v3.2/spinal_root_edge_unobserved.example.json) has zero observed axons.

The graph can enable a query such as: "Which FUNCTION_TESTED relation is linked to which actual, calibrated anatomical observation?" If the answer is no evidence or only a synthetic record, the query must return **UNRESOLVED**, not silently accept a theory.

A scientist should be able to retract an interpretation while preserving raw data and previous revisions. The absence of an edge might be **unobserved** rather than evidence of no biological connection, particularly when instrument coverage is incomplete.

## 8. Falsification and reporting rules

- If an axon-looking feature is unsupported by source/region/registration, do not classify a structural pathway as observed.
- If only activity covariance remains after valid controls, report ASSOCIATIONAL, not causal influence.
- If a physically separated source is functionally implicated but learned performance is unchanged, report a circuit result **without** claiming a stored Root.
- If a linked task improves only through teacher software, report **assisted use**, not independent biological learning.
- If a delayed result disappears after a rest interval, report the tested retention horizon and its negative outcome.
- If an assay detects KIBRA, BDNF, synaptic scaffolds or MCT pathways, report molecular source scope; their presence does not encode a book or explain learned semantics.

All outcomes, including falsification and technical limitations, enter the Animon scientific evidence ledger. The target label is "reviewable candidate experiment", not "Animon has acquired general memory".
