# Anaiero Native Reference

Static GitHub Pages developer documentation served from `docs/native-reference/`.

- Web entry: [index.html](index.html)
- Source manifest: [source-index.json](source-index.json)
- Runtime source branch: [design/v3.1-biological-systems-rigorous-spec](https://github.com/bradgearon/ChristEye-Knowledge/tree/design/v3.1-biological-systems-rigorous-spec/native)

The browser builds an in-memory index of class and callable declarations directly from public native headers via raw GitHub, and links each to its exact source line. No build step or third-party dependencies are required for publication. The index is source-derived and does not assert that a declaration has been experimentally validated.
