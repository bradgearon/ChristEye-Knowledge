# Test strategy and acceptance semantics

The existing P02B release documented 85 tests plus 100 parameterized subtests. Those are reported **historical software results**, not independently rerun on this GitHub copy or evidence of living tissue function.

## Cell-free acceptance

- Typed WindBus source/recipient versioning, idempotency and expired-message rejection.
- Synthetic acquisition: missing/stale channels, clock drift and response windows.
- Sealed evaluator: no outcome leakage until completion, explicit invalid statuses.
- Independent limit model: unauthorized physical actions rejected, faults latch and need review.
- Roots: delayed retention computed only when a baseline learning advantage exists, plus per-task protection.
- CrystalPack: content hashes, source permission checks, dependency graph, verified digital cloning and replay.
- Remote diagnostics: authenticated read-only compact messages; radio unavailable cannot interrupt care.
- Audit: append-only receipts, versioned configuration and detectable tampering.

## Research confirmation

Use the biological preparation (not electrodes/trials) as the independent replicate when appropriate. Report uncertainty, attrition, false alerts, training/test separation and predeclared controls. Distinguish task learning, delayed retention, added observer contribution and independent recipient acquisition.

## No validated physical release

P02C real-board power, EMI, watchdog and OEM inhibit tests are open. P03–P08 biological gates are open. A pass in the digital twin grants **no authorization** to actuate living equipment.
