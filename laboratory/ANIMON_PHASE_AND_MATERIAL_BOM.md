# Source-constrained physical bill of materials and phase sequence

The 2026-11-15 [P01 Physical Module Composition and Counts](../phases/P01/docs/01_Physical_Module_Composition_and_Counts.md) already established a **specific planar reference**, not a 3D Soil preparation. The operational work orders must respect it rather than presenting a new culture as though the entire Animon organoid starts at R1.

## 1. Which actual living preparation is proposed at each program milestone?

| Release | Source-backed candidate physical module | Reference count per well | What needs independent qualification |
|---|---|---|---|
| R0 | **digital reference, no tissue** | 0 cells | all event/reader/QA/consent/fault software and closed-loop simulator |
| R1 | C / Core learner: qualified **2D planar motor-neuron + matched astrocyte** supplier platform | **80,000 neurons + 20,000 astrocytes = 100,000 cells/well** in the original reference | actual pair, vendor-approved 24-well MEA compatibility, medium, substrate, viability and independent controls |
| R2 separate campaigns | O / Observer and B / Recipient, each qualified planar source | same **reference** 80k/20k **per distinct well** if the approved platform truly matches | independent source/recipient/reader arrangement, controls and no hidden teacher information |
| R3 | S / support-policy learner | same source-specific planar reference **if qualified** | independent policy benefit and safe non-actuating observation; no standalone "food chip" |
| P06 | **3D organoid Soil** branch and prospective spinal Root integration | **NOT SET** (different geometry) | separately selected model source, gas/solute exchange, 3D readout depth, phenotype and care |
| P07 | candidate physical Crystal carrier | **NOT SET** | existence, material boundary, specific learned relation, compatible reader and recipient; all unproven |

**Source warning:** The counts in R1/R2/R3 are a worked BrainXell/Axion reference associated with an illustrative 24-well MEA geometry, **not** a laboratory instruction to plate those numbers. The 3D organoid and additional immune/OPC/neuromodulatory populations explicitly cannot inherit that planar count.

The [P06 Lily–Lotus plan](P06-lily-lotus-regional-plan.md) names the first spatial comparison. It pairs a floor-plate organizer with identified spinal commissural axons and a registered receiving region, with support and readouts for both sides. Forebrain midline zipper glia and cortical Cajal–Retzius cells are separate comparison cohorts. Physical counts, ratios and yields for each 3D model are open.

## 2. Actual planning arithmetic — before vendor purchase

| Scenario | Verified calculation | What it does and does not establish |
|---|---|---|
| one illustrative planar C well | 80,000 neural + 20,000 matched astrocytes | 100,000 nominal cells; not a measured plated/viable count |
| illustrative R1 24-well comparison | 24 × 80,000 = **1,920,000 neurons**; 24 × 20,000 = **480,000 astrocytes** | **2.4 million nominal total** across four illustrative conditions × six wells; not a power calculation or approved replicate design |
| R2 separate O and B preparations | each additional well has an independent physical count | source/recipient arrangement and actual lab capacity must be designed; do not double count reused glial support |
| P06 prospective 3D Soil | no known source-qualified cell counts | **unresolved**, requires distinct approved institution method and longitudinal model qualification |

Lot ordering must separately account for actual vendor/vial capacity, receipt condition, viability/recovery, attrition, controls, assay/sampling, reserves, source variation and approved number of independent biological replicates. A cryovial label is not the true live plated amount. The supplier's actual current specification and scientist signoff are authoritative.

## 3. Which material and instrument classes are needed?

| Class | Actual research input or equipment reference | Required source/custody record |
|---|---|---|
| cellular source | authenticated source-qualified human neural and matched astrocyte lots (or explicitly chosen alternative approved model) | bank accession, source/consent, lot, passage, authentication, contamination/genetic QC |
| genomic/lineage source | original source STR/SNP identity and applicable karyotype/CNV; RNA/protein sampling under qualified SOP | specimen IDs, assay reference, model/genetic status, raw source file with restricted donor privacy |
| 2D neural interface | **vendor-compatible 24-well MEA hardware** in the source example | exact instrument serial/model, acquisition method, sample/channel identity, baseline and electrode controls |
| live maintenance | model-specific approved complete medium and separately specified environment | chosen manufacturer formulation/lot, source SOP and service/care receipts; not individual internet ingredient recipes |
| material observation | qualified cell morphology/identity, source-approved optical/electrical instruments | method, calibration, region/coverage, image and channel source |
| chemistry | calibrated source/sample analytes such as glucose/lactate, gases, pH/osmolality where method-qualified | specimen position/handling, unit, quantitation and assay validation |
| data/computation | WDS WindBus, MemoryBank, digital CrystalPack and frozen Root evaluator | software build/revision, permitted source rights, checksum, trace, protected old tasks |
| future 3D | a selected qualified organoid and spinal regional model, with additional model-specific constraints | source-controlled approved SOP and **new** dimensionality/viability/stage acceptance criteria |

**Molecules by role (from source P01 companion):**
- Qualified medium constituents: water, Na/K/Ca/Mg/Cl/HCO3- ionic context, glucose, pyruvate, amino acids/glutamine, lipids, vitamins and supplier supplement components **only as part of an approved complete formulation**.
- Production-stage/research candidates: retinoic acid/SHH, WNT/SMAD, BDNF/TrkB, GDNF, selected regulatory signaling — **not** a combination to add autonomously.
- Assay candidates: SOX2, neuronal MAP2/TUBB3/RBFOX3, spinal MNX1/ISL1/CHAT, astrocytic ALDH1L1/SOX9/GFAP, candidate neurite/synapse and receptor markers. The actual selected source/phenotype requires validated multi-marker profiling, not this list by itself.

For each category the scientist chooses an **approved method/SOP and its actual parameters**. No genome editing, new physical cell clone operation or peptide-induced "memory ingestion" is qualified by this table.

## 4. Scientist's first actual procurement gate

**The next executable procurement-related work is DOCUMENT REVIEW, not cell plating:**

1. Identify a qualified laboratory/cell science PI and the actual BrainXell/Axion-compatible reference source **or justify a different supplier/model**.
2. Obtain the current vendor specifications and actual source-line/matched-glia availability and legally permitted use.
3. Specify which R1 comparisons and independent source lines are required; use real statistical and attrition planning to calculate the number of cell lots and wells.
4. Obtain candidate MEA/instrument reference and calibration/control plan; confirm permitted maintenance SOP compatibility with the exact source pair.
5. Assign source QC (genetic identity, contamination and phenotype), genomic/RNA/protein assay owners and archive fields.
6. Ask the PI and care lead to sign actual model, SOP, environmental limits, cell count/plating quantities and method revisions. **Only then** can a facility write its source-specific physical work instruction.
7. Keep P06 3D Soil and spinal Root preparations on separate requirements and procurement lines; they are not a relabeling of R1 planar wells.

**Stop reasons:** unverified model/medium compatibility; absent cell-source rights; unknown source cell phenotype; unqualified electrical interface; no independent care owner; no valid experimental unit/comparator.
