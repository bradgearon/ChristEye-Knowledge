# What the fully composed Anaiero website should actually feel like

This is the design brief for the pages that must become the signature experiences. Each one has a reader question, a visual grammar, exact source material, interactive behavior and an honest scientific limitation.

## Page A — Project homepage: a statement, then proof

**Hero message:** "An architecture for learning, understanding and growth through connected systems." Subline: modular digital software and a research program for candidate biological computing. Do not state that a complete living mind already exists.

Visual: one elegantly composed layered system atlas, not dozens of overlapping panels. The Lotus coordinates; a clear typed WindBus enters specialist modules and digital Roots; the living Soil is one *proposed* experimental substrate; a separate independent limit controller is visible. Diagram shows only interactions backed by a source contract.

Second screen: six audience pathways. Third: real digital artifacts, illustrated with genuine recorded source output or deterministic client reproduction. Fourth: care and growth as measurable processes. Fifth: scientific frontier and limits. Footer: WDS license and source.

## Page B — Interactive anatomy of the system

**Question:** "How do the pieces talk to each other?"

The visitor can toggle **Software** and **Living Research** lenses and select Lotus, Heart, Spirit, Soil, Roots, Mesh, BioBridge, SustiBus and ChemiBus. Each opens a diagram pane containing "ordinary entity," "information exchanged," "what must be measured," "current status," "source spec" and "related science."

A timeline moves from first record → receiving state → training → retained Root → proposed Crystal. The animation does **not** show chemical knowledge transfer as already implemented.

## Page C — Growing a Soil / a Root

**Question:** "What grows, where, and what proves useful growth?"

A longitudinal, paper-like plate with 6 stages: source and lineage, observed cell production, spatial Soil, neurite/axon morphology, qualified I/O, and independently retained response. Each stage links a qualified source, molecule/structure assay, measured uncertainties and a human-led change approval process.

Interactive distinction:
- new cell division ≠ axon growth
- axon morphology ≠ functioning connection
- functioning connection ≠ stored knowledge
- delayed response ≠ portable physical Crystal

A visible "Crest Cell IDs" mini-diagram distinguishes source lot, shared lineage barcode and observation-specific cell UUID. There is no implication that every newly born cell contains a unique engineered DNA address.

## Page D — Care, Love and Power

**Care:** SustiBus and Milk: physical support continuity regardless of performance; source-qualified care receipts. Honey and encouragement belong to a different learning-feedback data path.

**Love:** human-centered design, dignity, voluntary interaction, source attribution, responsible experiments, emotional support by software within user-approved boundaries. Present the philosophy sympathetically, not as measured neural affect or consciousness.

**Power:** computation and storage throughput, electrical data channel budgets, latency, external power requirements, measured metabolism and biological resource constraints. No free-energy implications. A viewer may adjust **hypothetical** channel counts and immediately see the arithmetic.

Diagram columns: care/learning, provision/feedback, physical/semantic; colored but always labeled.

## Page E — Scientific atlas and molecule card

**Question:** "Which ordinary molecules and structures are relevant?"

Use the actual Anaiero molecular index and source evidence table. A search filter by:
- source/lineage
- neurons/axons/spines
- presynaptic/postsynaptic receptor/scaffold
- astrocytes and metabolism
- ECM and plasticity
- candidate Crystal structures.

A selected BDNF/TrkB card describes investigated forms, receiving site and why those findings **do not** equate to a readable peptide memory. A selected lactate card distinguishes measured amount, flux and memory correlation. Card includes source paper, date, preparation, effect, and missing experiment for this project. No dose recommendations or biological operation controls.

## Page F — The developer's CE-A02 dossier

**Question:** "How would I implement and verify this module?"

Tabs: Architecture / Full engineering design / Companion / Schemas / Data path / Tests / Sources. The page should show a code diagram of digital CAS write and read, a clean schema browser with real fields, a capability table, and a related panel explaining spinal Root/axon research as a separate hypothesis.

The bottom of the page allows viewing the **full original document**, not a shortened index, with stable anchors and permanent link to the exact Git blob revision.

## Page G — StarChip Studio

**Question:** "What can these proposed chips do?"

A gallery with seven user-relevant disciplines—game worlds, music, research, books, language, software tools and multidisciplinary composition. Each chip reveals its actual proposal manifest, interactions with other modules, input/output examples, expected acceptance metrics, and implementation readiness.

Actual executable digital examples are highlighted by working source/test evidence. Proposal-only game/music StarChips show beautiful *grounded output storyboards* with no fake play button. When implemented, the Metroidvania seed must pass a graph-solvability validator; the music MIDI example must use owned/public-domain musical material; the scientific theorist must expose uncertainty and sources.

## Page H — Scientist's workbench

**Question:** "What does the PI or cell foundry actually do at each stage?"

Render all 12 stages in the existing Scientist Workflow as a navigable, auditable timeline. Every stage exposes owner, input, output artifact, hold reason, independent controls, verified external source, and the next evidence gate. Use precise spatial representations of axons/glia rather than anthropomorphic cell language as if literal.

A visitor can select a hypothetical "growth request" and see why a human scientific review is required before changing care or peptides. There is no physical command issued.

## Page I — Scholarship and the history of the theory

**Question:** "Where do Word, Wind, Milk, Honey, Bread, Soil, Roots, Lotus and Heart come from, and why use them?"

This is a serious annotated essay, not a claim that a scriptural metaphor is a specific molecular fact. Use three labeled lenses: **text/interpretation**, **system design analogy**, **ordinary biological/computational referent**. Preserve dated project history and original WDS research sources. Scholars can follow citations and distinguish interpretations from experimental observations.

## Source and publication gating

Each storyboard must be editorially approved by WDS, source-mapped to the registry, reviewed for biological claim status, given a permanent route, and tested with no-JS reading, accessible diagrams and source links. A conceptual design sketch is never represented as an instrument measurement.
