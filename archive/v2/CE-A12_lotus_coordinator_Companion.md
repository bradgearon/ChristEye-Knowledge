Lotus Main Coordinator and Developmental Operating System — Technical Companion

Mechanisms, alternatives, evidence, metrics and engineering handoff

# 01 ChristEye role interpretation

Lotus: distributed scheduling and integration at host scale; Heart: biological role, not the external safety veto.

Assignments are scoped engineering roles, not a universal claim that a term is one molecule, cell type or brain region. Physical Soil denotes the living organoid as a whole; external medium and exchange are the Sea.

# 02 Scientific and computational standing

The word Lotus can name local physiological coordination or host governance when scale and mechanism are explicit. No single biological coordinator has been proven.

F = named published finding in its preparation; X = cross-study synthesis; H = untested hypothesis; D = design decision; A = analogy. An untested chain remains H even if its components are established separately.

# 03 Model and quantitative interpretation

## Constrained choice

Assumption / applicability: The limit controller L can veto regardless of the ranking outcome.

# 04 Data transformation and experiment logic

Input record: NeedRequest; current module state; protected Roots; available action catalog

Output record: DevelopmentDecision; staged plan; authorization request; performance receipt

Implementation decision rule: Estimate each action benefit vector and uncertainty; use a declared scalar ranking only after hard per-competency constraints; route physical actions to a separately approved controller, never direct autonomous operation.

## Counterfactual checks

- Safety veto cannot be overruled by utility

- Plans never run with missing parameter bounds

- Every action links to independent outcome evidence

# 05 Distinguish competing causes

- Uncalibrated reward may prioritize false metrics

- Recursive self-approval is forbidden

- Biological Lotus is not the host scheduler

Attribution rule: correlation, high activity, successful decoding, structural density, software adaptation and biological retention are different observations. Keep source attribution and negative controls before upgrading the claim.
