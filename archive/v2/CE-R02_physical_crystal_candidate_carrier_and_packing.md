# 1 Purpose and boundary

A formal research program for the proposed physical embodiment of acquired Knowledge/Understanding in living Soil. Candidate carriers include constrained neural circuits, postsynaptic assemblies and extracellular organization; none is a verified portable memory package.

# 2 Inputs

- Defined learned relation, paired baselines and protected other tasks

- Candidate physical state descriptors with source and measurement limitations

- Competing access, support, excitability and decoder explanations

# 3 Outputs / Winds

- CrystalCandidateRecord with carrier, boundary, content claim and reader contract

- Hypothesis-specific discriminating tests and negative findings

- Readiness decision for investigation, never automatic deployment

# 4 Required behavior

- Define packing dimension explicitly: volume, density, redundancy or description length.

- Separate retained response from physical evidence of its carrier.

- Investigate multiple mechanisms without collapsing BDNF, astrocytes and ECM into one memory molecule.

- Use health-preserving context controls; never infer memory from withdrawal of life support.

# 5 Processing and activation

> **1.** Establish an acquired task-dependent difference with sealed tests.
>
> **2.** Observe candidate local state differences linked to teaching histories.
>
> **3.** Ask whether that state predicts delayed content-specific performance beyond global activity.
>
> **4.** Seek qualified causal evidence distinguishing content from general support.
>
> **5.** Only then discuss whether a bounded organization could be installed or taught elsewhere.

# 6 Test and release gate

- Every Crystal claim names what is physically carried and independently decoded.

- No molecule is assigned a semantic bit capacity without an encoding/reader model.

- Physical installation remains out of scope until independent retention/transfer evidence exists.

# 7 Failure and protection

- Physical stabilization mistaken for symbolic memory transfer.

- Equivalent output hides a digital teacher or the host readout.

# 8 Open research and engineering questions

- Can multiple candidate carriers coexist and maintain task content through turnover?

# 9 Data contract and evidence trace

All calls use versioned request/response schemas. A WindEnvelope records source, recipient, trace_id, data type, delivered time, validity, provenance and uncertainty. Actual hardware commands, if any, require a separate approved permit. Performance claims cite evaluator runs with sealed test sets.
