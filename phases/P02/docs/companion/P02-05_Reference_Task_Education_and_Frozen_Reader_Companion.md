**Scope:** metrics, experimental confounds and the distinction between software and biological learning.

# 1. The biological learning claim has several independent parts

Input responsiveness is not acquisition; an immediate task-score improvement is not Roots; later response to a cue is not necessarily a content-specific engram; successful bridge-assisted output is not independent learning in the recipient. The experimental ladder explicitly separates interface competence, acquired discrimination, delayed retained ability, useful joined contribution and independent recipient acquisition. P02 can test that the measurement software enforces the ladder without supplying any positive biological result. \[I01\]

# 2. The truth table is discriminative by design

C0/AB and C1/AB have identical symbol order but opposite labels. C0/AB and C0/BA have the same symbols but opposite labels. AA/BB require HOLD rather than a class that could be inferred from symbol frequency. These contrasts expose shortcuts such as context-blind decisions, last-token classification or always-HOLD. A correct classification on an entire table learned by a Python dictionary is expected and trivial; it is useful only as a software instrument test. Before live training, any electrical encoding must show that different stimuli are physically separable and that labels cannot be predicted from accidental total charge, stimulus length or file name. \[I01\]

# 3. Why a frozen reader matters

An adaptive software classifier can improve while the underlying biological population remains unchanged, a distinction central to reservoir computing. To isolate biological change, freeze the encoding, channel map or preregistered registration method, preprocessing, decoder weights, thresholds, evaluation window and feature normalization. Re-training any of these yields a separate hybrid-adaptive-readout claim. The P02 FixedReader is a literal pass-through mapping and always has the same digest. A living experiment would require confirming its capacity and stability through locked development data before final tests. \[I01\]

# 4. Retention and uncertainty

For a three-class macro recall, a chance benchmark may be about 1/3 under properly balanced random predictions, but it must be constructed for the actual metric and class prevalence. The chance-corrected ratio R_U(Δ) = (P_Δ − P_0)/(P_immediate − P_0) becomes numerically unstable if the immediate advantage is small. An improvement after a support condition changes is consistent with preserved access but does not localize the storage trace; a failed recovery cannot demonstrate erasure. Test alternative cues and matched support without feeding the answer. Report the scored delay, probe repetitions, cohort, raw performance and confidence interval. \[I02\]

# 5. Proper experimental unit

Trials and electrodes from the same independently prepared organoid are nested observations, not independent biological replicates. Sample size must be based on expected between-preparation variation, effect size, attrition and specified analysis. For two-arm normal approximations, n/arm ≈ 2(z_α + z_power)^2 σ² / Δ² is only a planning starting point, not a complete design for bounded scores, multiple hypotheses or repeated measures. The P02 simulation's 24 training trials are bookkeeping examples; they are not a biological power calculation and should never define a live exposure quota. \[I02\]

# 6. Feedback is information, not reward chemistry

A training outcome provided after a response closes is described as Honey-like **selective guidance** in the ChristEye role language. It is a typed message with contingency, not an assumption that an electric pulse is pleasurable, painful or biologically reinforcing. Essential Milk-like metabolic support must remain independent of task success. A later study can compare contingency with a noncontingent exposure-matched control; matching energy alone does not match information, spatial coverage, timing or downstream physiology. \[I01\]

# 7. Extension paths

The next software education study can introduce genuinely held-out contexts and novel recombinations to assess transfer beyond the eight memorized keys, plus a model in which access failure and capacity loss can be independently manipulated. A future biological study must qualify the substrate and use independent delayed preparations to test retention, not borrow the deterministic synthetic outcome. P05 can then investigate whether O predicts core unreliability with strictly pre-outcome information and whether B retains independently after A's bridge and cache are absent. \[I01, I02\]

# Additional engineering annex: controls and future learning qualification

**Predeclared software baselines.** An exact truth-table oracle achieves perfect task labels and is only the source of answer truth. An always-HOLD response achieves 50% raw accuracy and 1/3 macro recall across the eight balanced cases; context-blind and last-symbol shortcuts should be tested separately. A frozen-readout learner changing its own state is the experimental target; an adaptive software decoder is a different hybrid mode. The present dictionary-like fixture passes by construction, so its score is a code-regression result, not evidence of neural plasticity.

**Independent living control ladder.** A qualified P04 design would compare independent preparations receiving contingent task feedback, matched noncontingent or yoked feedback, and untrained reference conditions. It would track invalid exposures and biological baseline drift. A separate evaluation cohort would be tested after a declared period without answer-bearing input, with test timing and probe history prespecified. A bridge study adds matched software teacher and shuffled partner controls; recipient B is assessed **alone** after clearing caches, teacher-derived normalization and current bridge messages. \[I01\]

**Forgetting versus access.** If a later score declines, test alternative previously valid cues and measurement conditions before claiming storage erased. Improvements after context restoration could indicate preserved access, recent retraining or instrument recovery; a single performance curve cannot uniquely identify which. The Root ledger should store the source of every cue, task family, immediate/delayed score, uncertainty interval, and all prior adaptations, so a new curriculum can be evaluated for interference. \[I02\]

**Claim boundary for this release.** No biological preparations were randomly assigned, no delayed neuronal memory was measured, and no astrocytic or molecular mechanism was tested. The synthetic learner has no causal model of cognition or affect. Its positive result is useful solely because it validates the event flow, feedback isolation, reproducible reader configuration and correct scoring before a laboratory expends samples.
