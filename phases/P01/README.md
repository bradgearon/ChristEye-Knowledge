## Reference versus hypothesis

An 80,000-neuron / 20,000-astrocyte worked example comes from a specific Axion/BrainXell planar MEA co-culture protocol; **it is not** an established Anaiero organoid formula. Exact 3D quantities, medium, feeding schedule, electrical waveforms and physical Crystals are separate unresolved qualifications. Software services begin with **zero** physically assigned cells.
